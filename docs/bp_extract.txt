Feature 2 — REPORT Permanently Warn Others After Being Scammed Any Nigerian who has been defrauded submits a verified fraud report. The system is designed to be fair to both sides — not a tool for false accusations — with identity verification, evidence submission, right of response, and a dispute resolution process built in from day one. Step Action Detail 1 Reporter Verifies Identity Reporter must verify their NIN or BVN before submitting. Anonymous reports are not accepted. This prevents malicious false reporting. 2 Submit Report Details Name, phone number, account number, or NIN of the alleged scammer. Type of fraud. Amount involved. Date. Description. Optional evidence upload (screenshots, receipts, documents). 3 Reported Person Notified The reported person receives a WhatsApp and SMS notification that a report has been filed against them. They have 14 days to respond or dispute. 4 Right of Response The reported person can submit their version of events. Both sides are displayed publicly on the report. VerifyNG does not adjudicate — it shows evidence from both sides. 5 Report Goes Live After 14 days (or sooner if response received), the report is published. It is permanently searchable. Only a court order or EFCC instruction can remove a verified report. 6 Escalation Option Reporter can opt to forward the verified report directly to EFCC, NPF-NCCC, or CBN with one click — pre-formatted with all evidence attached. FastAPI runs as a separate ASGI application mounted alongside Django, handling three specific responsibilities where its performance advantages matter most. How Django and FastAPI Work Together FastAPI handles: WhatsApp Business API webhooks (must respond within 20 seconds), real-time check queries (sub-100ms target), third-party API calls (NIN/BVN/WAEC — async, non-blocking) Django handles: everything else — user registration, report submission, profile management, admin, template rendering, Celery task dispatch They share: PostgreSQL database (Django ORM + SQLAlchemy in FastAPI), Redis instance, and AWS S3 for file storage Communication: FastAPI calls Django ORM models directly via shared database. For complex business logic, FastAPI calls Django&apos;s internal API endpoints rather than duplicating logic Deployment: both run in the same Docker network. Nginx routes /api/v1/* to FastAPI (Uvicorn), everything else to Django (Gunicorn) 4.5 WhatsApp Integration — How It Works The WhatsApp interface is the most important access point — because most Nigerians who need VerifyNG will never visit a website.
